# GitHub User Finder

## Автор
Имя Фамилия

## Описание
Приложение, которое позволяет искать пользователей на GitHub и добавлять их в избранное.

## Как использовать API
Приложение использует [GitHub API](https://api.github.com) для получения информации о пользователях.

### Примеры использования
1. Запустите приложение.
2. Введите имя пользователя и нажмите "Поиск".
3. Выберите пользователя из списка и добавьте его в избранные.
